# Software para poke bar y restaurante fast casual

Sistema para operar negocios donde el cliente pide en barra, elige ingredientes,
paga y el equipo prepara el pedido con control de inventario y operacion.

Este producto forma parte de Janco:
https://janco.tech/sistemas/restaurante

## Que resuelve

- Flujo de pedidos en barra.
- Control de ingredientes, recetas y mermas.
- Caja, ventas y cortes.
- Inventario y compras.
- Reportes para entender productos, sucursales y operacion.
